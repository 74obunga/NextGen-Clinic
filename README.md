# NextStep Clinic Website

A standalone React, TypeScript and Vite website for NextStep Prosthetics & Orthotics. It lives separately from the hotel management application.

## Run locally

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. The development server uses port `5174`.

## Build

```powershell
npm run build
npm run preview
```

The static production site is written to `dist/`.
